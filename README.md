## 🇩🇪 Deutsch

### Worum geht's?

Du startest als kleiner **Shrimp** und kämpfst dich als Bitcoin-Raumschiff durch Wellen von Gegnern. Sammle BTC, steige im Tier auf bis zum goldenen **Buckelwal 👑** und besiege am Ende den gefürchteten **ETH-Monster DeFi-Overlord**, um die Bitcoin-Blockchain zu retten.

### Features

- 🎮 **Arcade-Action** im Neo-Geo-Stil mit Neon-Optik und Retro-Sounds
- 🦐➡🐋 **8 Tier-Stufen:** Shrimp → Krabbe → Oktopus → Fisch → Delfin → Hai → Wal → Buckelwal
- 💥 **Waffen-Upgrades** durch Power-up-Münzen:
  1. Dual-Kanone
  2. Helfer-Schiff erscheint
  3. Helfer mit Dual-Kanone
  4. **Neon-Kanone** (mächtige pinke Durchschlag-Strahlen)
  5. **Neon-Streufeuer** für den Helfer
  6. Ab der 6. Münze: BTC-Bonus, der sich jedes Mal verdoppelt (+5, +10, +20, +40 …)
- 📈 **Rendite-Multiplikator:** Je mehr BTC du besitzt, desto höher dein Multiplikator (bis 128x)
- 👾 **Abwechslungsreiche Gegner:** BTC-Münzen, Spike-Minen, zielsuchende ETH- und USDT-Raketen
- 👹 **Endboss:** ETH-Monster DeFi-Overlord mit eigener Lebensleiste
- 🎬 **Finale:** Das Bitcoin-Whitepaper rollt als Abspann durch, danach gratuliert dir **Satoshi Nakamoto**
- 🌍 **Zweisprachig:** Deutsch und Englisch umschaltbar
- 📱 **Handy-tauglich:** Touch-Steuerung und als Web-App installierbar

### Steuerung

| Gerät | Bewegen | Schießen |
|---|---|---|
| **Tastatur** | Pfeiltasten oder `W` `A` `S` `D` | `Leertaste` |
| **Maus** | Maus bewegen | Maustaste gedrückt halten |
| **Handy / Tablet** | Schiff mit dem Finger ziehen | Automatisch beim Ziehen |

### Als App aufs Handy

Öffne das Spiel im Browser deines Handys und füge es zum Startbildschirm hinzu:

- **iPhone (Safari):** Teilen-Symbol → **„Zum Home-Bildschirm"**
- **Android (Chrome):** Menü ⋮ → **„App installieren"** oder **„Zum Startbildschirm hinzufügen"**

Im Spiel findest du dafür auch den Button **„Teilen oder App installieren"** auf dem Titelbildschirm. Er kopiert den Link und zeigt dir die Anleitung.

### Lokal starten

Das Spiel besteht aus einer einzigen HTML-Datei, es wird nichts installiert:

1. Repository herunterladen oder klonen
2. Die Datei `index.html` (bzw. `sb_V3.html`) im Browser öffnen
3. Spielen!

Für die Installation als Web-App müssen `manifest.json` und die Icons (`icon-192.png`, `icon-512.png`) im selben Ordner liegen.

## 🇬🇧 English

### What is it?

You start as a tiny **Shrimp** and fight through waves of enemies as a Bitcoin spaceship. Collect BTC, evolve all the way up to the golden **Humpback Whale 👑**, and finally defeat the dreaded **ETH Monster DeFi Overlord** to save the Bitcoin blockchain.

### Features

- 🎮 **Arcade action** in Neo-Geo style with neon visuals and retro sounds
- 🦐➡🐋 **8 tiers:** Shrimp → Crab → Octopus → Fish → Dolphin → Shark → Whale → Humpback Whale
- 💥 **Weapon upgrades** from power-up coins:
  1. Dual cannon
  2. Helper ship appears
  3. Helper with dual cannon
  4. **Neon cannon** (powerful pink piercing beams)
  5. **Neon spread fire** for the helper
  6. From the 6th coin on: a BTC bonus that doubles every time (+5, +10, +20, +40 …)
- 📈 **Yield multiplier:** the more BTC you hold, the higher your multiplier (up to 128x)
- 👾 **Varied enemies:** BTC coins, spike mines, homing ETH and USDT missiles
- 👹 **Final boss:** ETH Monster DeFi Overlord with its own health bar
- 🎬 **Finale:** the Bitcoin white paper rolls as end credits, then **Satoshi Nakamoto** congratulates you
- 🌍 **Bilingual:** switch between German and English
- 📱 **Mobile-friendly:** touch controls and installable as a web app

### Controls

| Device | Move | Shoot |
|---|---|---|
| **Keyboard** | Arrow keys or `W` `A` `S` `D` | `Space` |
| **Mouse** | Move the mouse | Hold the mouse button |
| **Phone / tablet** | Drag the ship with your finger | Automatic while dragging |

### Install as an app

Open the game in your phone's browser and add it to your home screen:

- **iPhone (Safari):** Share icon → **"Add to Home Screen"**
- **Android (Chrome):** Menu ⋮ → **"Install app"** or **"Add to Home screen"**

The title screen also has a **"Share or Install App"** button that copies the link and shows these steps.

### Run locally

The game is a single HTML file, nothing to install:

1. Download or clone the repository
2. Open `index.html` (or `sb_V3.html`) in your browser
3. Play!

To install it as a web app, `manifest.json` and the icons (`icon-192.png`, `icon-512.png`) must sit in the same folder.
